# ViolinDiff

Official **PyTorch implementation** of  
**"ViolinDiff: Enhancing Expressive Violin Synthesis with Pitch Bend Conditioning"**

**Keywords**: Violin Synthesis, Neural Audio Synthesis, Pitch Bend Modeling, Expressive Performance, Diffusion Models

- **arXiv**: [arXiv:2409.12477](https://arxiv.org/pdf/2409.12477)  
- **Demo Page**: [ViolinDiff-Demo](https://daewoung.github.io/ViolinDiff-Demo/)  
- **Hugging Face**: [dawokim/ViolinDiff](https://huggingface.co/dawokim/ViolinDiff)

## Overview

This repository provides the official PyTorch codebase for **ViolinDiff**, a diffusion-based model focused on generating expressive violin performances with an emphasis on **pitch bend modeling**. By incorporating pitch bend control into diffusion models, ViolinDiff aims to capture more realistic, nuanced violin timbres and performance styles.
This model is provided for non-commercial, research use only.
